# 021 · «Обзор»: необработанные обращения и воронка привязки Telegram

**Статус:** новая
**Кому:** чат живой панели (админка)
**Ветка:** `work/overview-signals`, от свежего `main`
**Раздел PROJECT_STATE:** **§169** — номер выдан оркестратором
**Заведено:** 2026-09-13

## Зачем — два случая за одну неделю

1. Ученики пишут через «Сообщить о проблеме», и пишут толково, со
   скриншотами — а обращения лежали со статусом «новое» с 3 августа,
   никто не смотрел. Четыре из семи оказались настоящими дефектами.
2. Привязка Telegram сломалась 08.09 (100 % → 20 % успешных), и три дня
   этого никто не видел: числа «ссылок создано / привязок состоялось»
   нет ни на одном экране.

Оба сигнала есть в базе, оба — про «что мне сделать сегодня», то есть
это «Обзор» (§147: список дел, каждое число — ссылка).

## Что сделать

На «Обзоре» две строки в списке дел:

- **«Необработанных обращений: N»** — `support_requests` со статусом
  `new`; ссылка на экран обращений; ноль — строка не показывается
  (правило §147: ноль честный, но список дел не про нули).
- **«Telegram за 7 дней: создано ссылок X, привязано Y»** — из
  `telegram_link_tokens` (созданные) и `telegram_connections`
  (`connected_at`); если Y/X ниже половины при X ≥ 5 — строка
  подсвечивается как проблема, тон `bad` (правило §152: цвет по смыслу).
  Ссылка — на журнал Telegram.

Числа — из `admin_school_stats` (§107), добавляюще: новые ключи, старые
не трогать. Один запрос на «Обзор» остаётся одним.

## Приёмка

отказывает; `npx tsc -b > log 2>&1; echo $?` последним; worktree со
своим `npm ci`; dev-сервер погасить.
