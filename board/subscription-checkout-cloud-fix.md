# Оформление подписки при аварийном облачном режиме — 12.11.2026

Владелец разрешил тестовую оплату на всех учебных курсах и прямой пуш в main.
Сдача ДЗ и пробников остаётся закрытой. Режим ЮKassa подтверждён владельцем;
секреты магазина и конфигурация вебхука через доступные инструменты не проверены.

Причины отказа: beginCheckout безусловно блокировал оплату в READ_ONLY_MODE;
checkout показывал «Тариф недоступен» при сетевой ошибке и продлении выключенного
тарифа; общий кэш тарифов мог наследовать пустой ответ другого пользователя.
Исправлены эти три пути. Замена выключенного тарифа ограничена тем же курсом,
новая цена видна до отправки формы. Чужие и неизвестные ID не подменяются.

Данные School изменены отдельно: audience=everyone, 13 новых месячных тарифов
по 500 рублей, пробный период активных тарифов 0. Витрина содержит 14 учебных
курсов (5 шаблонов исключены). Ранее пустые карточки математики связаны с
курсами «Ученики 2026-2027», для остальных добавлены отдельные карточки с
полными названиями. Существующие подписки и записи платежей не изменены.

Проверка чтения под authenticated: 14 доступных карточек, 15 активных тарифов.
Платёжная операция не запускалась; сквозная проверка ЮKassa остаётся необходимой.
