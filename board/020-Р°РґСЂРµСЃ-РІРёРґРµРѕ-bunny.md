# 020 · Форма материала: адрес видео Bunny приводится к рабочему виду

**Статус:** новая
**Кому:** любой свободный чат (зона: материалы темы / контур курса)
**Ветка:** `work/bunny-url-normalize`, от свежего `main`
**Раздел PROJECT_STATE:** **§168** — номер выдан оркестратором
**Заведено:** 2026-09-13

## Что случилось

Владелец 12.09 прикрепил два видео к темам руками, скопировав адреса из
панели Bunny: один как страницу «play»
(`https://player.mediadelivery.net/play/726880/<guid>`), второй как
прямой поток (`https://vz-….b-cdn.net/<guid>/playlist.m3u8`). Форма
приняла оба молча. В плеере платформы такие адреса не работают, в
статистике видео (§146, разбор `guid` из адреса) — не считаются.
Оркестратор поправил руками (карта, 13.09). Остальные 350 видео на
платформе — в одном формате: `https://iframe.mediadelivery.net/embed/726880/<guid>`.

## Что сделать

При сохранении материала с `kind = 'video'` любой из известных видов
адреса Bunny (`iframe.mediadelivery.net/embed/…`, `player.mediadelivery.net/play/…`,
`vz-*.b-cdn.net/<guid>/…`, голый `<guid>`) приводится к
`https://iframe.mediadelivery.net/embed/<library>/<guid>`; библиотека —
из адреса, если есть, иначе `726880` (наша, §146). Адрес не Bunny —
принимается как есть (внешние ссылки бывают). Нормализация — **одна
чистая функция** в `lib`, с тестом на каждый вид адреса; её же
использовать в §146, если там свой разбор `guid` (проверь, не заводи
второй).

Название пустое — подставить `title` из библиотеки Bunny, если оно
достаётся без нового запроса (кэш §146 хранит `videos[]` с `title`);
иначе оставить как есть, не выдумывать.

## Приёмка

Тест на пять видов адреса; сохранение через форму даёт embed-адрес;
существующие 352 строки **не трогать** (данные — не в этой работе).
`npx tsc -b > log 2>&1; echo $?` последним; worktree со своим `npm ci`.
