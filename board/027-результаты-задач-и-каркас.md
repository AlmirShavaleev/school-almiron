# 027 · «Результаты тестов» показывают задачи к уроку; каркас без ученических вкладок

**Статус:** новая
**Кому:** облачный агент оркестратора
**Ветка:** `work/course-task-results`, от свежего `main`
**Раздел PROJECT_STATE:** **§174** — номер выдан оркестратором
**Заведено:** 2026-09-14

## Зачем

Цепочка задач к уроку теперь замкнута почти целиком: преподаватель
подбирает задачи в каталоге и прикрепляет к теме каркаса (§164), они
сами появляются во всех классах (§172), ученик решает их по-степиковски
(§162). Не хватает последнего звена — **где преподаватель видит, кто
что решил по всему курсу**. Сейчас это видно только по одной теме, в
окне темы («задач к уроку: 10 · решают 12 из 16»), а вкладка курса
«Результаты тестов» показывает старые тесты из банка (`topic_tests`),
которых в живых курсах почти нет.

И второе, мелкое: владелец открыл каркас «Физика ЕГЭ Шаблон» → «Домашние
задания» и увидел «В курсе пока нет учеников». Это правда (ученики — в
классах-копиях), но в каркасе такие вкладки просто не нужны и сбивают.

## Часть 1 — вкладка «Результаты тестов» = задачи к уроку

В классе (не каркасе) вкладка `testresults` (`CourseProgramPage.tsx`,
`CourseTestResultsSection.tsx`) показывает первым и главным блоком
**«Задачи к уроку»**: таблица «ученик × тема».

- Столбцы — только темы, у которых есть набор задач
  (`test_variants.topic_id = тема`, §164), в порядке программы
  (модуль → тема). Тем без задач в таблице нет: пустые столбцы — шум.
- Ячейка: `решено / всего` (закрытые задачи, `closed_by is not null`,
  §162). Цвет по смыслу (§152): все закрыты — зелёный; часть — янтарный;
  ноль, но открывал — серый с числом; не открывал — пустая ячейка
  «—». Подсказка при наведении: «по ответу N · по разбору M»
  (`closed_by = 'auto'` / `'self'`).
- Строка ученика: имя (ссылка на `/students/:student_id?course=<id>`,
  §171) и итог «решено X из Y по курсу». Итоговая строка снизу: по каждой
  теме «решили все: K из N учеников».
- Ростер — из `group_students` курса, как в соседних вкладках; ученик
  без единой выдачи всё равно в таблице (ленивая выдача §164: строк
  варианта может не быть, пока тему не открыли).
- На телефоне (390): первый столбец с именем закреплён, темы
  прокручиваются по горизонтали внутри своего контейнера, страница
  целиком по горизонтали не едет (§158). Заголовки тем — коротко, с
  полным названием в `title`.

**Данные — одна RPC**, а не N запросов по темам:
`course_topic_tasks_matrix(p_course_id uuid)` — definer, доступ через
`course_is_staff(p_course_id)` (CLAUDE.md: любая новая проверка «персонал
ли» — только через неё), `revoke from public, anon; grant to
authenticated`. Возвращает строки `(student_id, full_name, topic_id,
topic_title, module_order, topic_order, tasks_total, touched, closed_auto,
closed_self)` — по одной на пару «ученик × тема с задачами»; ученики
без выдачи тоже присутствуют (`touched = 0`). Считать так же, как
`topic_task_progress_for_staff` (§164, миграция `20260912212817`), чтобы
числа в окне темы и в таблице совпадали — расхождение владелец заметит
первым. SQL — в `supabase/migrations/PENDING_174.sql`, не применять
(общие правила). Проверка прав в SQL-тесте описывается словами в
отчёте; оркестратор прогонит под учеником и посторонним преподавателем
при применении.

Старый блок с тестами из банка остаётся **ниже**, под заголовком «Тесты
из банка», и показывается только если у курса есть хоть одна строка
`topic_test_assignments`; иначе не рисуется вовсе. Его код не
переписывать — только обернуть.

Пусто (в классе нет ни одной темы с задачами): «Задачи к уроку ещё не
прикреплены. Прикрепляются в каркасе курса → тема → «Задачи» →
«Подобрать в каталоге»» — с названием каркаса, если курс — копия
(`courses.copied_from_course_id`).

## Часть 2 — каркас без ученических вкладок

Если `course.is_template`: вкладки «Домашние задания», «Результаты
тестов», «Ученики» **не показываются** (список вкладок в
`CourseProgramPage.tsx`, ~строка 2090; `COURSE_TABS` не трогать —
адрес `?tab=students` на каркасе просто открывает «Программа курса»).
Вместо них одной строкой под шапкой каркаса: «Каркас курса: ученики,
домашние задания и результаты — в классах: 10А, 11А, …» — названия
классов-копий по `copied_from_course_id`, активных, каждое — ссылка на
курс. Если копий нет — «копий курса пока нет».
