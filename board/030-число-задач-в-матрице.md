# 030 · «Материалы» курса: в столбце «Задачи» — число прикреплённых задач

**Статус:** новая
**Кому:** облачный агент оркестратора
**Ветка:** `work/materials-tasks-count`, поверх серии 026–029
**Раздел PROJECT_STATE:** **§177** — номер выдан оркестратором
**Заведено:** 2026-09-15

## Что показал владелец

Вкладка курса «Материалы» (`MaterialsMatrix` в `src/pages/CourseProgramPage.tsx`,
~строки 1051–1280): матрица «тема × рубрика» с ✓/✗ и полоса «1066 / 1690
заполнено (63 %)». У темы «Кинематика … Теория» в столбце «Задачи»
стоит ✗, хотя к ней прикреплены 10 задач к уроку (§164). Причина:
столбец `test` заполняется из `topic_test_assignments` — это старые
тесты из банка, а задачи к уроку живут в `test_variants.topic_id` +
`test_variant_items` (§162/§164) и в матрицу не попадают вовсе.

Просьба владельца: «пусть в материалах учителя будет видно количество
задач, прикреплённых к теме».

## Что сделать

1. В загрузке матрицы (`Promise.all` ~строка 1087) добавить четвёртый
   запрос: `test_variants` → `topic_id, tasks_count` для `topicIds`
   (`tasks_count` поддерживается `attach_catalog_tasks_to_topic`,
   `topic_task_detach_item` и синхронизацией §172 — отдельный подсчёт
   по `test_variant_items` не нужен). Пагинация как у первого запроса,
   если тем больше страницы PostgREST (у физики 169 тем — в одну
   страницу входит, но сделать одинаково).
2. Хранить счётчик отдельно от `Set` рубрик: `taskCounts:
   Record<topicId, number>`. Столбец `test` считается заполненным, если
   задач > 0 **или** есть привязка теста из банка (как сейчас) — полоса
   «заполнено» и итог по модулю учитывают и то, и другое.
3. Ячейка столбца «Задачи»: если задач > 0 — зелёный кружок с **числом**
   («10») вместо галочки, `title="Задач к уроку: 10"`; если задач 0, но
   есть тест из банка — галочка как сейчас, `title="Тест из банка"`;
   иначе ✗. Ширина кружка — та же 24 px, двузначное число помещается;
   трёхзначных не бывает.
4. Клик по числу — открыть окно темы на рубрике «Задачи»: в странице
   уже есть механизм `materialsTopic` + `tile=test` (§164,
   `topicReturnPath`) — использовать его, не заводить второй. Остальные
   ячейки не трогать.
5. На 390 матрица уже прокручивается по горизонтали (§158) — проверить,
   что число не ломает ширину столбца.

## Приёмка

- Тесты поведенческие на матрицу: тема с 10 задачами → «10» и заполнена;
  тема с тестом из банка без задач → галочка; ни того, ни другого → ✗;
  полоса «заполнено» считает обе; клик по числу открывает рубрику
  «Задачи» темы.
- Скриншот вкладки «Материалы» на харнессе на 1280 (фикстуры
  `test_variants` с `topic_id`/`tasks_count` добавить в `fixtures.mjs`)
  — в `../patches/030-shots/`.
- `npx tsc -b > tsc.log 2>&1; echo $?` последним; патч, отчёт.
