# 026 · Сдача ДЗ: файлы, которые платформа не покажет, не принимаются

**Статус:** новая
**Кому:** облачный агент оркестратора
**Ветка:** `work/homework-file-formats`, от свежего `main`
**Раздел PROJECT_STATE:** **§173** — номер выдан оркестратором
**Заведено:** 2026-09-14

## Что случилось

14.09 утром ученик сдал ДЗ восемью файлами `.dng` (Apple ProRAW —
«сырые» снимки с матрицы, 25–75 МБ каждый): выбрал их из медиатеки
айфона. Форма приняла молча, преподаватель открыл работу — пусто:
браузеры DNG не показывают. По базе: из 151 файла в сдачах 93 WebP,
27 JPG, 16 PNG, 7 PDF и эти 8 DNG — других «чужих» форматов нет.

Почему проскочило. Поле выбора объявляет `accept="application/pdf,image/*"`
(`HOMEWORK_FILE_ACCEPT` в `src/lib/topicHomework.ts`), а `image/*`
включает `image/x-adobe-dng`. Дальше `src/lib/imageCompression.ts`
пытается сжать картинку в WebP, декодер отказывает — и по своему главному
правилу («сжатие не имеет права ломать загрузку») модуль **возвращает
исходный файл**, который и уезжает в Storage сырым. Правило верное для
JPG, который не удалось пережать; для формата, который никто не сможет
открыть, оно превращается в тихую потерю работы.

## Что сделать

1. **Точный список вместо `image/*`.** `HOMEWORK_FILE_ACCEPT` →
   перечень того, что платформа показывает: `image/jpeg, image/png,
   image/webp, image/heic, image/heif, application/pdf` плюс расширения
   `.jpg,.jpeg,.png,.webp,.heic,.heif,.pdf`. Смысл не только в фильтре:
   iOS Safari при точном `accept` **сам конвертирует** HEIC (и, по
   опыту, ProRAW) в JPEG при выборе из медиатеки — большинство учеников
   проблему не увидят вовсе. Поле «Сфотографировать» (`accept="image/*"`
   + `capture`, §159) не трогать: камера из браузера RAW не снимает.
2. **Проверка формата ДО сжатия и загрузки** — одна чистая функция в
   `src/lib/topicHomework.ts` (например `homeworkFileProblem(file):
   string | null`): по `file.type`, а если он пуст — по расширению.
   Всё, чего нет в списке, отклоняется **до** `compressImage` и до
   Storage, с текстом для ученика без технических слов:
   > Этот формат (.dng) не откроется у преподавателя. Выключи RAW в
   > камере (Настройки → Камера → Форматы) или сфотографируй заново.
   Кнопка/ссылка «Сфотографировать» рядом с текстом — та же, что уже
   есть в форме. Остальные файлы из той же пачки грузятся как обычно;
   отклонённый не считается «выбранным».
3. `imageCompression.ts` не менять: его правило «никогда не ломать
   загрузку» остаётся, гейт стоит перед ним.
4. Место — путь сдачи ДЗ по темам (`TopicHomeworkStudent.tsx`,
   `useTopicHomework.ts`). Легаси `SubmitHomeworkModal.tsx` (контур V2,
   0 строк на проде) не трогать.

## Приёмка

- Тесты поведенческие: DNG (по mime и по расширению при пустом mime) →
  сообщение, в Storage не ушёл, `compressImage` не вызван; JPG/PNG/WebP/
  HEIC/PDF → путь как раньше; пачка «два JPG + один DNG» → два
  загружены, один отклонён с сообщением.
- Скриншот формы с сообщением на 390 — на харнессе (`e2e/harness/`,
  README там), если сцена сдачи ДЗ есть; нет — сказать, не снимать на
  проде.
- Существующие 8 DNG в базе не трогать — данные не в этой работе.
- `npx tsc -b > tsc.log 2>&1; echo $?` последним. Патч и отчёт — по
  общим правилам.

**Проверка владельцем после слияния (не эмулируется):** iPhone с
включённым ProRAW, выбор из медиатеки → ожидаемо либо пришёл JPG (iOS
сконвертировала), либо сообщение. «Загрузилось и пусто» — дефект.
