# Локальный курс «ЕГЭ 2 ч ТЕСТ»

Из корня рабочей ветки запустите `node e2e/harness/photo-course.mjs`. Откройте [тригонометрический демо-урок](http://127.0.0.1:5243/__photo_course/student) или [очередь преподавателя](http://localhost:5243/__photo_course/teacher). Тестовые попытки хранятся в памяти стенда. Для запросов ИИ используется демонстрационный ответ.

## №14 · Стереометрия

В исходной папке №14 должны быть 21 папка «Урок NN - …» и папка «Теория и Шпаргалки». Подготовьте манифест и изображения условий с помощью Python (пакеты `pdfplumber`, `Pillow`) и Poppler (`pdftoppm`):

```powershell
python e2e/harness/prepare-ege14.py "D:/путь/№14" "D:/путь/временный-курс"
$env:ALMIRON_EGE14_MANIFEST = 'D:/путь/временный-курс/ege14.json'
node e2e/harness/photo-course.mjs
```

Если `pdftoppm` отсутствует в PATH, передайте путь к программе через параметр `--pdftoppm`. Манифест, исходные PDF и изображения остаются локальными.

В [списке уроков](http://127.0.0.1:5243/__photo_course/course) появится модуль «№14 · Стереометрия». [Первый урок](http://127.0.0.1:5243/__photo_course/section-14) открывается сразу на вкладке ДЗ.
